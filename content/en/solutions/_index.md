A solution package turns a scenario into **filter conditions + recommended parts + toolchain + risks**. Each one links to an MCU filter you can open directly, so you can swap parts or widen the candidate set.

If you have a concrete project, send it in through the selection request form and we will turn the reusable parts into a new package.
