This catalog covers publicly documented RISC-V MCUs and wireless SoCs. Each record aims to include **clock speed, SRAM, Flash, active and sleep power, peripheral instance counts, package, temperature range, ecosystem, and data sources**; fields that are not public are left empty rather than estimated. Pricing is limited to verifiable volume reference prices — where no public price exists, we show "inquire".

Filters support multi-select, range search, and combined conditions, and the current selection is synced to the URL so you can send a set of criteria straight to a colleague. Tick 2–4 parts to compare them side by side; the comparison can be shared by URL.
