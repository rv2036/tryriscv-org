## なぜ tryriscv.org を作ったのか

RISC-V のデバイス数はこの 3 年で急速に増えましたが、情報は断片化しています。メーカー公式サイトは「代表的な用途」を、データシートは「電気的特性」を、代理店は「価格」を、コミュニティは「つまずきどころ」を語ります。選定を担当するチームに**足りないのは文書の量ではなく、絞り込み・比較・出典の追跡ができる 1 枚の表**です。

tryriscv.org の目的は、公開情報を構造化データとして整理し、「100MHz 前後、低消費電力、64KB メモリ、BLE が必要」といった実際の要件を、数分で試作可能な数点のチップに絞り込めるようにすることです。

## データの出典

- メーカー公式サイトの製品ページ、データシート、リファレンスマニュアル、選定表
- メーカー公式の GitHub / SDK ドキュメント / ツールチェーンページ
- 公開されている業界団体、コミュニティ、代理店の資料（相互検証のみ）

各レコードには `sources` と `confidence` のフィールドを持たせています。非公開のパラメータは `null` とし、当て推量の推定は行いません。mA から換算した µA/MHz は、消費電力の備考に条件を明記しています。

## 現在の対象範囲

- **MCU**：沁恒、兆易创新、乐鑫、博流、爱普特、芯昇、先楫、联盛德、泰凌微など。継続して追加中です。
- **IP**：平头哥玄铁、芯来 Nuclei、赛昉 Dubhe、SiFive、晶心 Andes など
- **ソリューション**：IoT 産学連携、低消費電力センシング、BLE、Wi-Fi、モーター制御、産業制御
- **AI 演算**：プレビュー版。NPU IP と AI SoC のハードウェアおよびツールチェーン情報

## ロードマップ

1. 中国製 RISC-V MCU の消費電力、パッケージ、価格のデータを充実させ、四半期ごとの見直し体制を整えます。
2. 「IP / AI コンポーネント / モデル / ソフトウェアバージョン」の適合成熟度マトリクスを追加します。
3. コミュニティによる実測（消費電力、起動時間、RTOS 移植、モデル推論）と再現可能なベンチマークを導入します。
4. ソリューションパッケージに参考回路図、BOM、教材用の実験案を追加します。

## 中立性と訂正

本サイトはメーカーの有料掲載を受け付けていません。並び順は既定で「データの完全性 + 低消費電力 + コスト」の総合評価としており、ユーザーが自由に切り替えられます。パラメータの誤り、リンク切れ、型番の漏れを見つけた場合は、[GitHub Issues](https://github.com/rv2036/tryriscv-org/issues) に型番をタイトルへ入れてご報告ください。
