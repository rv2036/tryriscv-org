## 为什么做 tryriscv.org

RISC-V 的器件数量在过去三年快速增长，但信息是碎的：厂商官网给“典型应用”，数据手册给“电气参数”，代理商给“价格”，社区给“踩坑经验”。对一个要选型的团队来说，**缺的不是更多文档，而是一张能筛、能比、能追溯来源的表**。

tryriscv.org 的目标是把公开信息整理成结构化数据，让“100MHz 左右、低功耗、64KB 内存、要 BLE”这类真实需求，在几分钟内收敛到几颗可打样的芯片。

## 数据从哪里来

- 厂商官网的产品页、数据手册（Datasheet）、参考手册与选型表；
- 厂商官方 GitHub / SDK 文档 / 工具链页面；
- 公开的行业联盟、社区与代理商资料（仅作交叉校验）。

每条记录保留 `sources` 与 `confidence` 字段。未公开的参数写 `null`，不做“拍脑袋”估算；由 mA 换算的 µA/MHz 会在功耗备注中说明条件。

## 当前覆盖

- **MCU**：沁恒、兆易创新、乐鑫、博流、爱普特、芯昇、先楫、泰凌微等，持续补充；
- **IP**：平头哥玄铁、芯来 Nuclei、赛昉 Dubhe、SiFive、晶心 Andes 等；
- **解决方案**：IoT 产教融合、低功耗传感、BLE、Wi-Fi、电机控制、工业控制；
- **AI 算力**：预览版，NPU IP 与 AI SoC 的硬件与工具链信息。

### 已排除的非 RISC-V 器件（更正）

联盛德 W800 / W801 / W806 使用 XT804（玄铁 E804，C-SKY 架构），官方 SDK 使用 `csky-elfabiv2` 工具链，并非 RISC-V。此前将其按 RV32IMAC 收录属于误判，现已从 MCU 库移除。8051/ARM 内核的型号同样不纳入本库；如果你发现其他误收，请提交 issue。

## 路线图

1. 补全国产 RISC-V MCU 的功耗、封装与价格数据，建立按季度复核机制；
2. 增加“IP / AI 组件 / 模型 / 软件版本”的匹配成熟度矩阵；
3. 引入社区实测（功耗、启动时间、RTOS 移植、模型推理）与可复现的 benchmark；
4. 为方案包补充参考原理图、BOM 与教学实验建议。

## 中立性与纠错

本站不接受厂商付费排名。排序默认按“数据完整度 + 低功耗 + 成本”综合，用户可自由切换。若发现参数错误、链接失效或型号遗漏，请到 [GitHub Issues](https://github.com/rv2036/tryriscv-org/issues) 提交，标题里带上型号即可。
